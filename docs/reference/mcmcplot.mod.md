# Plot MCMC draws

A modified version of the mcmcplot() function from the mcmcplots.
Modified to not automatically open the html file that is created. This
version creates and saves various plots and an HTML file collecting them
(but does not automatically open the HTML file.) This function is not
intended to be called by users directly.

## Usage

``` r
mcmcplot.mod(...)
```

## Arguments

- See:

  mcmcplot() from mcmcplots() package.

## Value

See mcmcplot() from mcmcplots() package.
