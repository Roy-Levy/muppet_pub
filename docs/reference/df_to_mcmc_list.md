# Converts a dataframe to an mcmc.list object

This is an internal function, and is not intended to be called by users
directly.

## Usage

``` r
df_to_mcmc_list(df, chain_col = "Chain.number", iter_col = "Iteration.number")
```

## Arguments

- df:

  The dataframe to be converted to an mcmc.list object

- chain_col:

  Do not alter

- iter_col:

  Do not alter

## Value

An mcmc.list object
